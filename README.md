# نبهان | Video Editor — محمد نبهان

موقع شخصي (Portfolio) احترافي ثنائي اللغة (عربي / English) لمحمد نبهان — مونتير فيديو ومصمم موشن جرافيك.
بموضوع داكن وأجواء غرفة المونتاج: تايم لاين، وقت كودي شغال، لافتة مشهد/تك/رول، حواف فيلم،
وخط سكان — وكمان مؤثرات ماوس وأصوات وزرار ألوان.

---

## 1) التشغيل محليًا

افتح `index.html` دوبل كلك في أي متصفح — الموقع يشتغل مباشرة من غير سيرفر.

---

## 2) هيكل الملفات

```
nabhan-portfolio/
├─ index.html          ← الصفحة الرئيسية
├─ admin.html          ← لوحة تحكم (تعدّل منها بدون كود)
├─ css/style.css       ← التصميم
├─ js/content.js       ← كل المحتوى (النصوص + المشاريع + الروابط)
├─ js/main.js          ← المنطق والعرض والمؤثرات
├─ assets/fonts        ← فونت Panorama Naskh
├─ assets/img          ← الصور
├─ assets/videos       ← الفيديوهات
├─ robots.txt          ← للمحركات البحثية
├─ sitemap.xml         ← سايت ماب (عدّل الرابط قبل الرفع)
└─ README.md
```

---

## 3) إضافة مشروع / فيديو / صورة

### من لوحة التحكم (الأسهل)
1. افتح `admin.html`.
2. قسم **06 المشاريع** ← **+ إضافة مشروع جديد**.
3. حط اسم الصورة والفيديو:
   - صورة الغلاف: `assets/img/my-thumb.jpg`
   - الفيديو: `assets/videos/my-reel.mp4`
   - أو رابط يوتيوب embed وفعّل خيار **يوتيوب/فايمو (embed)**
4. **تنزيل content.js** ← وانقل الملف لمجلد `js` واستبدل القديم.

### يدويًا
حط الصور في `assets/img` والفيديوهات في `assets/videos`، وعدّل `js/content.js`.

> رابط يوتيوب لازم يكون بصيغة التضمين:
> `https://www.youtube.com/embed/VIDEO_ID?autoplay=1`

## 6) المؤثرات الصوتية

زرار الصوت في الهدر يفتح/يقفل (بيتحفظ اختيارك)، والقيمة الافتراضية من `meta.sound` في `content.js`.

## 7) الألوان

زرار الدائرة في الهدر يغيّر لون الأكسسنت (6 ألوان) — بيتحفظ في `localStorage`.

## 8) ملاحظات تقنية

- الفونت العربي **Panorama Naskh** (محلي). محدود بـ `unicode-range` للعربية، فالأرقام والحروف
  اللاتينية تسقط على **Plus Jakarta Sans** — عشان الأرقام تظهر في الاتنين.
- لون الهوية والصوت واللغة الافتراضية يتغيروا من `content.js` أو لوحة التحكم.
- كل الموقع ملفات ثابتة — مفيش سيرفر أو قاعدة بيانات.
